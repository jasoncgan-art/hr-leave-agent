# Leave Request Process — Acme Corp (fictional)

Last updated: 2026-03-01. This document is fully synthetic and written for a
software demo. It is not real legal or HR advice.

[Section: REQ-1] Planned leave. Planned PTO requests must be submitted through
the leave-ticket system at least 14 calendar days before the first day of
leave. Each ticket receives a confirmation number and a decision within 2
business days.

[Section: REQ-2] Sick leave. For unplanned sick leave, notify your manager
before the start of the workday and file a ticket the same day when possible.

[Section: REQ-3] Extended and protected leave. Requests for parental leave,
family medical leave, or unpaid leave longer than 5 days require HR review in
addition to manager approval. Submit at least 30 calendar days in advance when
foreseeable.

[Section: REQ-4] What to include. Every ticket must include the employee ID,
leave type, start date, end date (or expected return date), and a brief reason.
